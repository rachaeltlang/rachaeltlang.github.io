安裝指南

在 Target 的第二次實習輪調期間，我和我的實習夥伴合作，為技術庫存工程團隊設計並實現了一個動態安裝指南。該指南在 Target 的長期計劃中發揮關鍵作用，該計劃旨在全面編目所有硬體技術資產。我們使用 Adob​​e XD 從零開始繪製了詳細的線框圖， 並專注於考慮了可訪問性，以確保用戶擁有包容性的體驗。本指南使用 TypeScript 和 React 構建，打造了一個流暢且動態 的使用者介面。我們還進行了廣泛的跨瀏覽器相容性測試，以確保在不同的網頁瀏覽器和裝置上功能一致。

DormNomNom

這是我在威斯康辛大學麥迪遜分校「行動系統與應用基礎」課程中，與四位同學組成的團隊共同完成的一個學期期末專案。 DormNomNom 是一款專為威斯康辛大學麥迪遜分校學生宿舍住校生設計的安卓應用程式。該應用程式利用了學生宿舍用於顯示餐廳菜單的 API。 菜單提供營養信息，DormNomNom 允許用戶在餐食中添加食物並追蹤宏量營養素的攝取量。應用程式啟動後，也會使用定位服務自動向 使用者顯示最近的餐廳。

獾麵包店

獾麵包店是一個 React Native 應用程式，它調用自訂 API 以取得烘焙食品數據，然後將數據展示給使用者。我實現了分頁、 數量增減、計算訂單總額和顯示提示框等功能。該應用程式已使用 Expo Go 進行測試。
