Installation Guide

We also conducted extensive cross-browser compatibility testing to ensure consistent functionality across different web browsers and devices.

DormNomNom

This was a semester-long final project I completed on a team of four for the Foundations of Mobile Systems and Applications course at UW-Madison. DormNomNom is an Android app designed for students living in University Housing at UW-Madison. The app utilizes the API University Housing uses to display the menu at the dining halls. The menu provides nutritional information, and DormNomNom allows users to add food items to meals and keep track of macronutrients. Upon launching, the app also uses location services to automatically show users the closest dining hall.

Check it out on GitHub

Badger Bakery

Badger Bakery is a React Native application that makes calls to a custom API to retrieve data on baked goods, then displays the data to the user. I implemented functions such as pagination, increasing and decreasing quantity, calculating an order total, and displaying an Alert. This was tested using Expo Go.
