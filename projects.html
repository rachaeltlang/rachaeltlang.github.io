DormNomNom

This was a semester-long final project I completed on a team of 4 for the Foundations of Mobile Systems and Applications course at UW-Madison. DormNomNom is an Android app designed for students living in University Housing at UW-Madison. The app utilizes the API University Housing uses to display the menu at the dining halls. The menu provides nutritional information, and DormNomNom allows users to add food items to meals and keep track of macronutrients. Upon launching, the app also uses location services to automatically show users the closest dining hall.

Check it out on GitHub

React Native Applications

The following are React Native applications I developed for the Building User Interfaces course at UW-Madison. The apps were tested using Expo Go.

Badger Bakery

The Badger Bakery application makes calls to a custom API to retrieve data on baked goods, then displays the data to the user. I implemented functions such as pagination, increasing and decreasing quantity, calculating an order total, and displaying an Alert.

Check out a demo video here

Badger News

The Badger News application makes calls to a custom API that pulls news from the UW-Madison website and displays each news article as a Card. I also implemented React Navigation, and Animation, icons, and links.

Check out a demo video here

Badger Chat

The Badger Chat application allows users (students in the course) to create an account and login to post to one of several chatrooms. Users are able to create posts, delete posts, toggle between different chatrooms, browse as a guest, and sign out. Functions implemented include pagination and making POST and DELETE requests to an API.
